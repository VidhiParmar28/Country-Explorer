# 🌍 Country-Explorer

A responsive web application built using **HTML, CSS, and JavaScript** that allows users to search and explore countries around the world. The application fetches real-time country data from a public API and dynamically displays country information as the user types.

## 🚀 Features

- 🌎 Fetches country data using the Fetch API.
- 🔍 Search countries by name.
- 📋 Displays country details dynamically.
- ⚡ Instant search with real-time filtering.
- 📱 Responsive and user-friendly interface.
